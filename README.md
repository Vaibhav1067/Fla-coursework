# FLA Coursework (21CSC301T)

Interactive exam playbook for Formal Language and Automata, built from six past papers (Nov 2024 to May 2026).

- `index.html`: the complete single-file app. Open it in a browser.
- `src/`: sources (`engine.js` automata/grammar/PDA/TM/PCP engines, `presets.js`, `data.js`, `app.js`, `style.css`), `build.py` to assemble, `test.js` to verify the engines.

Contents: topic priority matrix, study plan, NFA to DFA, DFA minimization, Mealy/Moore, CFG simplification/CNF/GNF, PDA and CFG to PDA, Turing machine simulator, PCP solver, and a Part A quiz.
